# kbdflag-rs

Плавающий флаг раскладки клавиатуры рядом с курсором. Показывает текущий язык ввода (RU/EN) в виде флага, который можно перетаскивать, масштабировать и кликом переключать раскладку. Живёт в системном трее.

Разработано под **KDE Plasma / X11** (ALT Linux 10.4), но должно работать на любом Linux-десктопе с X11 и StatusNotifierItem-совместимым треем.

## Возможности

- Флаг текущей раскладки (RU/EN) в отдельном маленьком окне поверх всех окон.
- **Клик** по флагу — переключение языка (через `XkbLockGroup`, без переписывания XKB-конфига — индикатор раскладки KDE не ломается).
- **Перетаскивание** — зажать ЛКМ и двигать.
- **Масштаб** — колесо мыши над флагом.
- **Режим «следовать за курсором»** (включается из трея) — флаг плавает рядом с курсором.
  - Зажми **Ctrl** — флаг замирает, можно кликнуть или перетащить.
  - Отпусти **Ctrl** — снова следит за курсором.
- **Глобальная горячая клавиша** `Alt+Shift` / `Ctrl+Shift` (по `L`/`R`) — переключение раскладки, синхронизируется с системой.
- **Трей** (KDE SNI):
  - Переключить язык
  - Следовать за курсором (галочка)
  - Выход
- Автоопределение текущей раскладки при запуске.
- Окно не появляется на панели задач и в списке окон.

## Требования

- Linux с X11 (не Wayland)
- Rust 1.70+
- `libX11` (заголовки и библиотека)
- Рабочий StatusNotifierItem-агент в трее (в KDE Plasma есть из коробки)

sudo apt-get install libX11-devel
